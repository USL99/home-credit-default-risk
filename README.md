# Home Credit Default Risk

Учебный проект по машинному обучению на основе соревнования Kaggle
Home Credit Default Risk.

## Структура проекта:

Проект состоит из следующих частей: 
-  Анализ данных (EDA)
- Реализация моделей, необходимых для решения задач проекта
- Исходные данные, загруженные с Kaggle
- Подготовленнные данные для обучения моделей
- Файлы для отправки на Kaggle
- Графики
